# xr-survive-game

> 判断一件事值不值得继续；当你卡住或能量很低时，给出一个五分钟内能完成的动作。

## 安装

```text
https://github.com/xiran1984/xrskill，安装其中的 xr-survive-game
```

## 怎么用

```text
/xr-survive-game 我每天都在研究个人 IP，却一直没有实际产出，这件事值得继续吗？
```

## 可以问什么

```text
/xr-survive-game 我是不是在浪费时间？
/xr-survive-game 我不知道现在该做什么。
/xr-survive-game 这件事值得继续吗？
/xr-survive-game 我完全没动力，给我一个五分钟任务。
/xr-survive-game 我一直在学习，却迟迟没有开始做，问题在哪里？
```

它会根据问题进行意义评估、识别手段与目的混淆，或者直接给出一个低阻力微动作。

## 例子

```text
用户：/xr-survive-game 我想做自媒体，但研究了三个月还没发出第一条内容。这件事值得继续吗？

助手：先不讨论“适不适合做自媒体”，因为你现在同时混着两个问题：方向是否真实，以及执行为什么停滞。我要先判断你追逐的到底是收入、能力、关系资源，还是“成为自媒体人”这个身份。

你现在把时间和注意力主要花在自媒体的哪件事上？不用修饰，直接说。

用户：看教程、研究平台规则，还在想自己适合做什么方向。

助手：目前看，你投入的主要是“理解自媒体”，不是“制作和发布内容”。这不等于方向一定是假的，但意味着你还没有进入能够产生现实反馈的部分。

先做第一道投影测试：如果只用一句话说明，自媒体最终会怎样增加你的钱、可交易技能、健康或关系网络？不要回答“提升自己”或“打造个人品牌”，说一个能够观察到的现实结果。

用户：我希望以后能靠它赚钱，也想认识一些同行，但现在还没有任何收入。

助手：这句话能够投影到两个真实资源：收入和同行关系，所以第一项暂时通过。但“希望以后”还不是证据；它只能说明目标不是纯概念，不能证明你现在的路径有效。

第二道是手段—目的测试：如果明天所有自媒体平台都消失了，但你仍能通过别的方式赚钱、展示能力并认识同行，你失去的究竟是什么？是一个必要渠道，还是“我是自媒体人”这层身份和想象？

用户：如果还能赚钱和认识同行，我应该不会太在意平台。我真正想要的是不只靠上班挣钱，也希望有人看见我的能力。

助手：第二项也通过。你追的不是平台本身，而是额外收入、能力证明和关系入口；自媒体只是候选手段，不需要被当成人生身份。这一点很重要，因为手段无效时可以换，不必把放弃某个平台理解成自己失败。

现在做第三道信息差测试：过去两周，你投入在看教程、研究规则、选方向上的时间占多少；真正用于写稿、录制、发布或获取反馈的时间占多少？给一个大概比例。

用户：研究和准备大概占九成，真正写东西不到一成，而且什么都没发。

助手：这里出现了第一个明确红灯：连续三个月把九成时间放在理解和准备，却没有发布、交易或外部反馈。你不是在稳定地做自媒体，而是在用“我还需要弄懂一点”推迟接受市场检验。继续增加教程不会解决这个问题，因为你缺的已经不是信息，而是一次真实输出形成的反馈。

目前不能直接判定整件事该放弃：投影测试和手段—目的测试通过，信息差测试失败。下一轮要检查奖励回路——最近一周，你完成过哪个与自媒体有关、能明确说“做完了”的具体动作？

【示例截取至此，对话尚未结束：Skill 还会继续完成奖励回路与替代性测试，再输出完整判断或进入五分钟行动导航。】
```
