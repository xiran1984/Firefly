# xr-trauma-support

> 通过低压力对话识别心理卡点，先承接情绪，再寻找安全、可执行的恢复方向。

## 安装

```text
https://github.com/xiran1984/xrskill，安装其中的 xr-trauma-support
```

## 怎么用

```text
/xr-trauma-support 我知道应该开始，但一想到失败就会僵住并责备自己。
```

## 可以问什么

```text
/xr-trauma-support 过去的经历一直影响我，我该怎么办？
/xr-trauma-support 我总觉得只有对别人有用才值得被爱。
/xr-trauma-support 我明明处在安全环境里，还是会觉得别人想控制我。
/xr-trauma-support 以前做什么都没用，现在我也觉得行动无法改变结果。
/xr-trauma-support 我一直后悔当年的选择，无法停止责备自己。
```

它会按“创伤识别—情绪宽慰—解决方法”逐步对话。所有来源判断都只是允许用户否定的假设，不会把推测当成事实。

## 例子

```text
用户：/xr-trauma-support 我一犯小错，就会自动觉得自己整个人都没有价值。

助手：这听起来很累：事情本身可能只需要补救，但你的内心会立刻把它升级成“我这个人不行”。于是你承受的不只是错误的后果，还要同时承受羞耻和自我否定。

我先提出一个可以被你否定的假设：真正触发你的可能不只是犯错，而是“犯错之后会被人否定整个人”的旧警报。这个理解与你接近吗？

用户：很接近。我父母以前经常因为小错误骂我没用。

助手：那就能理解为什么现在的小失误会引起这么大的反应。小时候，错误没有被当成一个可以修改的行为，而是经常变成“你没用”的证据。一个孩子长期处在这种评价里，很容易学会在别人开口前先审判自己，仿佛责备得够快、够狠，就能避免下一次攻击。

这不是说自我攻击是好的，而是它可能曾经承担过保护作用。现在犯错的一瞬间，你最害怕接下来发生什么？

用户：我怕别人失望，然后觉得我什么都做不好。

助手：你怕的并不只是“这件事做坏了”，而是一次失误会让别人撤回认可，最后证明你什么都做不好。这样一来，完美就不再只是做事标准，而像是维持关系和自我价值的条件。

你似乎既很想被看见、被肯定，又不敢相信这种肯定能经受一次失误，所以先攻击自己成了避免别人失望的办法。这个理解与你接近吗？

用户：是的，但我还是控制不住第一反应。

助手：控制不住第一反应，并不代表你真的认同它。自动反应出现得比理性判断快，是因为它被重复了很多年；修复也不是要求你从明天起再也不自责，而是在旧警报出现之后，逐渐增加一个属于现在的第二判断。

比如先把“我没价值”改写成两个可以处理的问题：“实际造成了什么后果？”以及“我现在能补救哪一步？”在继续之前，我想确认你现在的感受是否还在可承受范围内，愿意尝试这样一个很小的练习吗？

用户：可以。

助手：那我们暂时不追求“停止自责”，只建立一个更现实、可观察的目标：发生小失误后，允许旧警报出现，但先判断真实后果、完成一次补救，不再直接把行为等同于整个人的价值。

接下来我会根据一个真实但低风险的场景，把这个目标拆成可以退出的小步骤。先只选一个触发点：最近最容易让你立刻觉得“我没用”的，通常是哪一种小错误？

【示例截取至此，对话尚未结束：Skill 会继续确认具体触发点，经用户同意后再形成一个安全、可退出、可观察的下一步。】
```

本 Skill 只提供创伤初筛与自助支持，不替代诊断或专业治疗。出现自伤、伤人或现实暴力危险时，应优先寻求现实中的紧急与专业支持。
