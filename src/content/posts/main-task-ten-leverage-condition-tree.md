> 目标：长期维持个体存在并实现代际传递——身体不崩、持续被需要、影响力可复制、资产可传承。

## 优先级总览

这里的优先级不按年龄或固定阶段划分，而按**现金续航期**动态调整。

> **现金续航期 = 可立即动用的现金及低风险资产 ÷ 每月体面生活成本**
> 
> 计算时假设未来没有新增收入；不计入自住房、长期锁定资产、信用额度和尚未兑现的应收款。  
> “体面生活成本”不是最低生存成本，而是维持正常居住、饮食、医疗、社交和工作状态所需的真实月支出。

下列权重表示各杠杆应占用的**注意力、时间和精力比例**，不是资金配置比例。总和为 100%，用于决定一个阶段“主要做什么、少做什么、暂时不做什么”。

### 权重总表

| 现金续航期    | 健康  | 无条件自信 | 信息差 | 作品  | 标准化流程 | 形象  | 自媒体内容 | 人脉  | 演讲  | 资产  |
| -------- | ---:| -----:| ---:| ---:| -----:| ---:| -----:| ---:| ---:| ---:|
| 少于 1 个月  | 20% | 5%    | 5%  | 10% | 5%    | 2%  | 3%    | 5%  | 0%  | 45% |
| 1—3 个月   | 20% | 8%    | 7%  | 15% | 5%    | 3%  | 5%    | 7%  | 0%  | 30% |
| 3—6 个月   | 18% | 8%    | 10% | 18% | 8%    | 5%  | 8%    | 8%  | 2%  | 15% |
| 6—12 个月  | 16% | 8%    | 10% | 20% | 10%   | 5%  | 10%   | 10% | 3%  | 8%  |
| 12—24 个月 | 15% | 7%    | 10% | 18% | 12%   | 5%  | 15%   | 10% | 5%  | 3%  |
| 24 个月以上  | 15% | 5%    | 10% | 15% | 12%   | 5%  | 15%   | 10% | 8%  | 5%  |

### 少于 1 个月：止血与恢复现金流

**目标：不是发展，而是避免失去选择权。**

| 优先级 | 杠杆          | 关键动作                                        |
| --- | ----------- | ------------------------------------------- |
| 核心  | 资产          | 立即压缩固定支出、催回应收款、出售闲置资产、寻找最快可兑现的工作或服务；禁止高风险投资 |
| 核心  | 健康          | 保住睡眠、基本饮食和最低运动量，避免因透支身体进一步降低赚钱能力            |
| 重要  | 作品          | 只做能够直接证明能力、获得面试、客户或订单的最小作品                  |
| 辅助  | 人脉 + 信息差    | 联系能够提供订单、岗位、客户线索和真实市场信息的人                   |
| 暂缓  | 演讲、自媒体、形象升级 | 除非能在 30 天内直接带来现金流，否则暂停投入                    |

### 1—3 个月：建立最低安全边界

**目标：把“随时断粮”变成“拥有一次试错机会”。**

| 优先级 | 杠杆       | 关键动作                               |
| --- | -------- | ---------------------------------- |
| 核心  | 资产       | 将续航期推到 3 个月；提高稳定收入，控制固定成本，不进行重资产投入 |
| 核心  | 健康 + 作品  | 恢复稳定工作节奏；持续交付可收费、可求职、可获客的作品        |
| 重要  | 无条件自信    | 用持续履约和小额成交恢复行动能力，而不是依靠心理暗示         |
| 重要  | 人脉 + 信息差 | 集中寻找有明确需求、预算和决策权的人，不做无目的社交与信息消费    |
| 暂缓  | 演讲       | 没有稳定现金流前，不为远期影响力投入大量训练时间           |

### 3—6 个月：从求生转向能力积累

**目标：既维持现金流，又开始建设不会随工资停止而归零的能力。**

| 优先级 | 杠杆          | 关键动作                                |
| --- | ----------- | ----------------------------------- |
| 核心  | 作品 + 健康     | 建立稳定产出节奏，形成可验证的作品组合，同时避免用过度工作换短期安全感 |
| 重要  | 资产          | 补足 6 个月缓冲，配置基础保险；投资以低风险、低维护为主       |
| 重要  | 信息差 + 标准化流程 | 找到高价值问题，将重复交付过程文档化，提高单位时间收入         |
| 建设  | 自媒体 + 人脉    | 开始低频但持续地公开输出，让机会能够主动找到你             |
| 试水  | 演讲          | 只进行小规模内部分享或低成本训练                    |

**目标：减少对单一雇主、客户和个人工时的依赖。**

| 优先级 | 杠杆        | 关键动作                          |
| --- | --------- | ----------------------------- |
| 核心  | 作品        | 建立系列化作品和代表性案例，让能力可以被第三方快速判断   |
| 核心  | 标准化流程     | 把高频工作沉淀为 SOP、模板和自动化流程         |
| 重要  | 信息差 + 自媒体 | 围绕真实市场需求持续输出，验证内容能否带来询盘、合作或收入 |
| 重要  | 人脉        | 建立稳定的合作层和信息层，不再依赖临时求助         |
| 维护  | 资产        | 维持现金缓冲并开始长期被动投资，不追求短期高收益      |

### 12—24 个月：放大有效路径

**目标：把已经验证的能力、作品和渠道放大，而不是继续增加新方向。**

| 优先级 | 杠杆           | 关键动作                         |
| --- | ------------ | ---------------------------- |
| 核心  | 作品 + 自媒体     | 打磨代表作，扩大高质量内容的分发与复用          |
| 核心  | 标准化流程        | 从个人流程升级为可委托、可自动化、可产品化的系统     |
| 重要  | 信息差 + 人脉     | 加深专业护城河，进入更高质量的客户、同行和合作网络    |
| 建设  | 演讲           | 将成熟观点训练成公开表达、课程或销售能力         |
| 维护  | 健康 + 形象 + 资产 | 保持稳定基线；投资和形象进入低频维护，不抢占核心创造时间 |

### 24 个月以上：长期下注与资产化

**目标：用足够长的安全期承担短期不回报、但长期回报非线性的项目。**

| 优先级 | 杠杆            | 关键动作                              |
| --- | ------------- | --------------------------------- |
| 核心  | 作品 + 自媒体      | 建设长期品牌、知识产权、产品和内容资产               |
| 核心  | 标准化流程         | 将个人能力转化为系统、团队、产品或可授权资产            |
| 重要  | 信息差 + 人脉 + 演讲 | 扩大行业影响力、合作半径和一对多传播能力              |
| 维护  | 资产            | 做分散配置、风险控制和被动收入再投资，不因现金充足而提高投机比例  |
| 底线  | 健康            | 仍保持至少 15% 权重；任何长期项目都不能以不可逆健康损失为代价 |

### 动态切换规则

1. **每月重新计算一次现金续航期。** 收入不稳定、支出上升或家庭责任变化时立即重算。
2. **按当前续航期配置，不按理想中的未来配置。** 只有现金已经到账，才允许进入下一阶段。
3. **续航期跌破阶段下限时立即降级。** 例如从 7 个月跌到 5 个月，应切回“3—6 个月”配置。
4. **🔴 归零风险高于所有权重。** 严重健康问题、成瘾、违法风险、债务违约等一旦出现，立即暂停其他杠杆并优先修复。
5. **权重是资源上限，不是待办数量。** 一个阶段最多设置 2 个核心杠杆、2—3 个重要杠杆，其余只做最低维护。
6. **稳定收入是修正项，不是现金替代品。** 收入越稳定，可以越接近该阶段的进攻型配置；收入高度波动时，即使账面续航期相同，也应向前一阶段降一级执行。

## 优先级推进逻辑

```
🟡 健康地基 + 自信地基 + 生存基金
 │
 ├── 不完成 → 禁止推进
 │
 └── 完成 → 🟢 信息差 + 形象 + 资产缓冲
                │
                └── 完成 → P2 作品 + 流程 + 自媒体 + 人脉
                               │
                               └── 完成 → P3 放大 + 演讲 + 收入多元
                                              │
                                              └── 完成 → P4 长期优化
                                                             │
                                                             └── 完成 → P5 代际传递
```

> **核心约束：**
> 
> - 任何 🔴 归零风险节点被触发时，暂停所有其他路径，优先修复。
> - 🟡 不完全 → 🟢 不启动。🟢 不跑通 3 个月 → P2 不启动。以此类推。
> - 优先级可因个人情况调整，但不可降级 🟡。
