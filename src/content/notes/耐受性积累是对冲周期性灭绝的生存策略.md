## 机制

大逃杀演化模型揭示了一种高压存量博弈下的生存逻辑：

```
系统崩溃(大灭绝) → 资源重组 → 幸存者扩张 →
积累期(耐受性积累) → 熵增到临界 → 再次崩溃
```

在两次崩溃之间，个体的核心动作是**耐受性积累**：在资源边际效用递减的环境中，通过极度自我压榨来积累硬通货（土地、权力准入、关系网）。目的不是改善生活质量，而是构建**防御性护城河**。

## 这套逻辑解释了

| 现象 | 底层逻辑 |
|------|----------|
| 囤积癖好 | 对未来灭绝周期的对冲 |
| 过度教育 | 维持不可替代性以防被洗牌 |
| 集体主义 | 动荡期的风险共担机制 |

在这个模型中，生存不是一种权利，而是一种**通过积累稀缺资源赢得的博弈结果**。
