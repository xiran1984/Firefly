## 核心内容

一套模因只要能降低竞争者的行动意愿，就会在文化演化中被自然选择、传播、强化、内化为"清醒"和"现实"。它们最常见的形态不是恶意的打压，而是以关心、稳妥、成熟的面貌出现——"普通人就过普通人的日子""人这一辈子平安就好""少做梦多认命"。这些话不阻止你努力，只阻止你把努力组织成策略；不阻止你吃苦，只阻止你思考"为什么我总是在吃低收益的苦"。

## 展开说明

策略性思考被污名化的映射表：

| 策略行为 | 被污名化为 |
|----------|-----------|
| 进取心 | 不安分 |
| 计算得失 | 功利 |
| 学习规则 | 圆滑 |
| 争取资源 | 不要脸 |
| 自我定价 | 自私 |
| 长期规划 | 想太多 |
| 退出低质量关系 | 薄情 |
| 拒绝低回报牺牲 | 不懂事 |

结果是：一个资源本就不多的人在道德压力下主动卸掉自己最重要的工具——判断、比较、规划、谈判、选择和退出。他以为自己是在保持纯粹，实际上是在放弃筹码。**越是资源匮乏的人越需要策略性思考**，因为有资源的人可以用试错覆盖愚蠢，而穷人的每一次选择都更重。

## 关键词含义

- **策略性思考**：不是在每个时刻"算计"，而是对自己人生变量的主动管理——知道资源有限所以排序，知道时间不可逆所以取舍，知道自己会被环境塑形所以主动选择环境
- **模因的自然选择**：不需要阴谋论——任何能降低竞争者行动意愿的文化模因都会在竞争中胜出，被传播、强化、内化
