## 核心内容

六条路径按资源要求从高到低排列：

| 路径      | 适用条件     | 关键动作                    |
| ------- | -------- | ----------------------- |
| 名校借势    | 考试能力强    | 关注新兴赛道或垄断行业就业机会         |
| 省直/央直编制 | 考试能力中等以上 | 考取省级或中央直属编制             |
| 技能+外语出海 | 考试能力一般   | 学一门技能和外语并考证，去海外项目       |
| 认知清洗    | 所有人必经    | 清除原生环境的乡愿和创伤，避免面子税      |
| 新兴行业学徒  | 年轻有时间    | 在还有 5 年以上红利的行业当学徒积攒第一桶金 |
| 周期资产配置  | 已有积蓄后    | 通过对周期律的理解配置资产获取被动收入     |

## 展开说明

认知清洗被放在第四条但实际上是**所有路径的前提**。原生家庭环境差的人最大的负债不是没钱，而是脑子里被植入的各种错误信念——"稳定最重要"、"做生意有风险"、"别人会怎么看你"——这些信念会让人在每一步选择中都倾向于保守和退缩，从而错过所有翻身的机会窗口。

出海路径在当下尤其值得关注：中国企业在海外的建设、工程和业务需要大量懂技能懂外语的人，供给严重不足。

## 关键词含义

- **面子税**：因为在意他人的看法而放弃更优选择所付出的隐性成本，是底层向上流动的最大阻力之一
