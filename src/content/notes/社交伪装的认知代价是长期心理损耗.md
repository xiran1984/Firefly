## Masking 的本质

用认知系统的**"手动挡"**模拟直觉系统的**"自动挡"**——刻意学习眼神接触、点头时机、话题切换、语气调整等神经典型者无意识完成的社交行为。

表面上"看不出来有什么不同"，但背后是**持续的认知超载**：每一个社交互动都在同时执行两项任务——实际对话处理 + 对自身社交表现的实时监控与校正。

## 代价链条

```
双任务并行 → 社交后极度疲劳 → 长期累积 → 焦虑障碍 + 抑郁 + "我到底是谁"
```

## 更优路径

Masking 不是一个可持续策略。更有效的方向不是让 ASD 个体"学会伪装得更好"，而是**让环境对不同沟通模式有更高的兼容性**。


- ASD 沟通模式以信息交换为第一目的
- 自然社交语言以关系维护为第一目的
