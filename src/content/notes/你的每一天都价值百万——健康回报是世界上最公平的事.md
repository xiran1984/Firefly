## 日常健康栈

| 领域 | 最小行动 |
|------|----------|
| **运动** | 升降桌站坐交替 + 每天快走 40 分钟 + 力量训练（快走燃脂效率 > 跑步） |
| **饮食** | 168 饮食法（16h 禁食）+ 先蔬菜再蛋白再碳水 + 鸡蛋是最好的食物 |
| **防护** | 戴墨镜（紫外线伤眼不可逆）+ 晒太阳 15min + 3C 认证头盔 |
| **牙齿** | 牙线 + 巴氏刷牙法，牙齿炎症与老年痴呆高度相关 |
| **医疗** | 肠胃镜定期做 + 建立家庭电子病历 + 原研药不省那点钱 |


- 四线并行——普通人最朴素的财富自由路径
- 七年就是一辈子三年足以彻底改变
