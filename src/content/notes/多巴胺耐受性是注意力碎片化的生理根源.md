## 随机比率强化

推荐算法的核心不是"猜你喜欢"，而是利用**奖赏预测误差**控制多巴胺能神经元。多巴胺不负责快乐，它负责渴望和动机。

当手指划动屏幕时，大脑处于极端不确定性中——下一条是惊喜还是无聊？这种**随机比率强化**是所有成瘾机制的核心。腹侧被盖区的多巴胺释放频率在随机奖励下显著高于固定奖励。

## 阈值拉高的后果

```
以前：3000 字文章 → 读完
后来：140 字微博 → 读完
现在：15 秒视频 → 倍速看完
```

这不是忙，是**多巴胺受体下调**。看书、深度交谈、逻辑思考产生的多巴胺释放量，已无法跨越被拉高的兴奋阈值。"脑子转不动"的本质是**戒断反应**。


- 短视频在主动重塑大脑而非被动生锈
- 认知分层是算法时代信息茧房的必然结果
